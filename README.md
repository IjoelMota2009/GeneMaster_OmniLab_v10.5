🔬 Sobre o Projeto
O Gene-Master Omni-Lab é uma ferramenta de bioinformática universal desenvolvida em Python. O software permite a visualização prática do Dogma Central da Biologia Molecular, oferecendo simulações de edição genética e análise de impacto funcional.

🚀 Funcionalidades Principais
Agnóstico a Organismos: Funciona com sequências de DNA humano, viral, bacteriano ou sintético.

Simulação CRISPR-Cas9: Ferramenta de edição manual e automática (Auto-CRISPR) para clivagem de sequências alvo.

Análise de Impacto Funcional: Identifica mutações de sentido trocado e erros de matriz de leitura (frameshifts).

IA Predictive Score: Algoritmo que calcula a divergência genética entre a sequência original e a modificada.

Eletroforese Virtual: Simula o movimento de fragmentos em gel de agarose baseado no par de bases (bp).

Exportação Científica: Gera relatórios técnicos em .txt com logs detalhados do experimento.

🛠️ Tecnologias Utilizadas
Python 3.13

Tkinter (Interface Gráfica)

PyInstaller (Compilação para Executável)

📊 Como Testar
Insira uma sequência de DNA (ex: Insulina Humana ou SARS-CoV-2).

Clique em DEFINIR BASE para estabelecer a referência.

Utilize o MUTADOR ou CRISPR EDIT para alterar a sequência.

Clique em TRADUZIR e COMPARAR para ver o impacto na proteína.

EXPORTAR o relatório final para documentação.
